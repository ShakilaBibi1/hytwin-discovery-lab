# HyTwin Discovery Lab — deployment checklist

The conference website is a static, self-contained HTML prototype. Keep this repository private during scientific and visual review.

## Upload the current prototype

1. Download `HyTwin_Discovery_Lab_v6.zip` from the ChatGPT conversation.
2. Extract the archive on your computer.
3. In this repository, choose **Add file → Upload files**.
4. Upload the extracted `index.html` to the repository root (not the ZIP itself).
5. Commit the upload to `main`.

The HTML includes its own embedded images, including the researcher portrait and anatomical illustrations. The `optional_images/` directory is not required for the initial standalone prototype.

## Before publication

- Confirm all five pages load on desktop and mobile.
- Verify all anatomical imagery and scientific claims against the manuscript and Circulation paper.
- Confirm permissions for the portrait, institutional branding and any manuscript findings.
- Connect and test the question form (currently a prototype).
- Do not upload private HyTwin model files, individual participant data or credentials.
- Publish only after explicit approval. GitHub Pages availability depends on repository visibility and account plan; a public repository is an option after approval.
